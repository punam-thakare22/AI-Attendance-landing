# SnapClass - Landing Page

Marketing/landing page for **SnapClass**, an AI-powered attendance system that uses face recognition and voice biometrics, with teacher and student portals, QR class joining and attendance analytics.

- **Live app:** https://ai-smart-snapclass.streamlit.app/
- **App source code:** https://github.com/punam-thakare22/AI_Attendance

## Tech
Flask (Jinja template), plain HTML/CSS/JS. Hosted on Vercel.

## Run locally
```
python -m venv venv
venv\Scripts\activate        # Windows  (macOS/Linux: source venv/bin/activate)
pip install -r requirements.txt
python app.py
```
Open http://localhost:5002
